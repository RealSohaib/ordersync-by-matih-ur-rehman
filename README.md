# OrderSync

OrderSync is a full-stack rfid based web application for managing orders, inventory, and accounts. It includes both a backend API and a frontend client, built with Node.js, Express, MongoDB, React, and Vite.

## Features

- **Order Management**: Place, edit, and delete orders.
- **Inventory Management**: Add, edit, and delete inventory items.
- **Account Management**: Manage financial accounts with credit and debit entries.
- **Responsive Design**: Mobile-friendly interface.
- **Real-time Updates**: Live search and filtering.
- **Notifications**: Toast notifications for various actions.
- **Printing**: Print receipts and other documents.
- **Authentication**: User authentication and role-based access control.
